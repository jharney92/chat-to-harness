Phase 2: Setup / Module 04

The terminal

The text window where agents do their work. You need about fifteen commands and a clear sense of which folder you are in.

45 minutesFree

What it is

The terminal is a window where you control your computer by typing instead of clicking. Everything you do in Finder, such as opening folders, creating files and moving things, you can do here with short commands.

It matters because this is where agents work. Claude Code runs in a terminal. So do the tools that host your app, manage your database and save your work. You do not need to become fast at it. You need to know where you are, how to move, and how to read what comes back.

Reading the prompt

Every line in a terminal starts the same way. Here is what each part means.

1
jack@macbook
2
~
3
%
4
ls
1
Who you are. Your username and your computer's name.
2
Where you are. The folder you are currently in. The ~ symbol means your home folder.
3
The prompt. It means the terminal is waiting for you to type.
4
Your command. Nothing happens until you press Enter.

Set it up

1
Open the terminal your Mac already has

Press Cmd + Space, type Terminal, and press Enter. A window with a blinking cursor appears.

2
Install Homebrew

Homebrew is an app store you use by typing. Go to brew.sh, copy the one-line install command at the top of the page, paste it into the terminal and press Enter.

It will ask for your Mac password. As you type it, nothing appears on screen, not even dots. That is normal. Type it and press Enter.

Do not skip the last part
When Homebrew finishes it prints a short section called Next steps, with two or three commands. Copy each one, paste it and press Enter. If you skip this, the brew command will not be found.
Type this
brew --version
You should see: a line starting with Homebrew and a version number.
3
Install Ghostty

Ghostty is a faster, nicer terminal app. It needs no configuration.

Type this
brew install --cask ghostty

You can also download it from ghostty.org and drag it into Applications. Open Ghostty from now on. The built-in Terminal still works for everything in this guide if you prefer it.

4
Make a home for your projects

Keep every project in one folder called Code inside your home folder.

Type this
mkdir ~/Code
cd ~/Code
mkdir first-project
cd first-project
pwd
You should see: a path that ends in /Code/first-project.

How your files are organized

Your Mac's files form a tree. Your home folder sits near the top and holds Desktop, Documents, Downloads and now Code. In the terminal a folder is often called a directory, and the route to a file is called its path.

The terminal is always inside exactly one folder, called the working directory. Commands act on that folder unless you say otherwise. Most beginner errors come from being in a different folder than you thought. When confused, type pwd.

The 15 commands that matter

You will use the first six constantly. The rest come up a few times a week.

Command
What it does
Example
pwd
Shows which folder you are in.
pwd
ls
Lists what is in the current folder.
ls
cd
Moves into a folder.
cd first-project
cd ..
Moves up one level.
cd ..
cd ~
Jumps back to your home folder.
cd ~/Code
mkdir
Makes a new folder.
mkdir notes
touch
Makes a new empty file.
touch ideas.txt
open
Opens a file or folder the normal Mac way.
open .
cat
Prints a file's contents in the terminal.
cat ideas.txt
cp
Copies a file.
cp ideas.txt backup.txt
mv
Moves or renames a file.
mv ideas.txt plan.txt
rm
Deletes a file. There is no Trash and no undo.
rm backup.txt
clear
Clears the screen.
clear
which
Shows whether a tool is installed and where.
which brew
brew install
Installs a tool with Homebrew.
brew install gh

Four keys worth knowing

Key
What it does
Tab
Finishes a file or folder name for you. Type the first few letters and press Tab.
Up arrow
Brings back the last command you ran. Press again to go further back.
Ctrl + C
Stops whatever is running and gives you the prompt back.
Cmd + T
Opens a new tab in the same terminal window.

Try it

Do this once, slowly, reading what comes back after each line.

Type each line, pressing Enter after each
cd ~/Code/first-project
touch notes.txt
ls
open .
mv notes.txt ideas.txt
ls
cd ..
pwd

A Finder window opened on the fourth line. Keep it visible and watch the file rename itself on the fifth. The terminal and Finder are two views of the same files.

When something goes wrong

What you see
What it means
What to do
command not found
You mistyped the command, or the tool is not installed.
Check spelling. Then run which followed by the tool's name.
No such file or directory
The file or folder is not where the terminal is looking.
Run pwd and ls to see where you are and what is there.
Permission denied
You are trying to change something outside your own folders.
You are probably in the wrong place. Go back to cd ~/Code.
Nothing happens and no prompt
A program is still running.
Wait a moment. If it stays stuck, press Ctrl + C.
brew: command not found
Homebrew's Next steps were skipped.
Scroll up to find them, or run the installer again and follow them.
