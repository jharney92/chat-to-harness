Phase 2: Setup / Module 06

Claude Code: first session

Install the agent, have it build a web page in your practice folder, and finish with your first runbook and your first handoff.

60 minutesUses your Pro plan

What you are about to do

Install Claude Code, start it inside your practice folder, and have it build a small web page while you watch. Then you will change the page by asking, save the work with Git, and write your first runbook.

Nothing here can damage your computer. Claude Code asks before it creates or changes files, and you are working in a folder that holds nothing important.

Install and sign in

1
Install Claude Code
Type this
curl -fsSL https://claude.ai/install.sh | bashirm https://claude.ai/install.ps1 | iex

This shows no progress while it downloads. Leave the window alone and wait.

You should see: Claude Code successfully installed!
2
Check it worked

Open a new terminal window or tab first, then run this.

Type this
claude --version
You should see: a version number followed by (Claude Code).
3
Start it in your project
Type this
cd ~/Code/first-project
claude

Always start Claude Code from inside the project folder. The folder you start in is the one it can see and change.

4
Sign in

The first time, it asks you to log in. A browser window opens. Sign in with the Claude account you set up in Module 3. You only do this once.

You should see: the Claude Code welcome screen, with a box to type in.

Build something

1
Ask what it can do
Type this to Claude
what can Claude Code do?

You talk to it in plain English. There is no special syntax.

2
Give it a real task
Type this to Claude
Make a one-page website for a fictional coffee shop called Second Shift.
Put everything in one file called index.html.
Include a headline, three menu items with prices, and opening hours.
I can open the file in my browser and see the finished page.

Notice the last line. It states what done looks like, starting with I can. That is the habit from Module 2.

3
Read the request, then approve

Claude will show you what it wants to create and ask permission. Read it. Then choose Yes. You are approving a specific action, which is the whole point of the default setting.

4
Look at the result

Open a second terminal tab with Cmd + TOpen a second terminal tab with Ctrl + Shift + T so Claude keeps running in the first.

Type this
cd ~/Code/first-project
open index.htmlstart index.html
You should see: the coffee shop page in your browser.
5
Change it by asking
Type this to Claude
Make the headline larger, use a dark green and cream color scheme,
and add a short paragraph about the owner.

Approve the edit, then refresh the browser tab.

6
Save your work
Type this to Claude
commit my changes with a descriptive message, then push to GitHub

Watch what it runs. You will recognize the four steps from Module 5.

Keys and commands inside Claude Code

Type or press
What it does
Esc
Interrupts Claude while it is working. Use it the moment you see it heading the wrong way.
/help
Lists the available commands.
/clear
Wipes the conversation and starts fresh in the same folder.
/exit
Leaves Claude Code. Pressing Ctrl + D twice does the same.
Up arrow
Brings back your previous message.
Shift + Tab
Switches permission mode. Leave it on the default for now. Phase 4 explains when and how to loosen it.
claude -c
Run from the terminal, this continues your most recent conversation in that folder.

How to ask well

The quality of what you get back depends mostly on how you ask.

Be specific
Name the thing and the problem
Instead of asking it to fix the page, say: the menu prices are left-aligned and I want them right-aligned on the same line as each item.
Say what done looks like
Finish with an I can sentence
I can click the email address and it opens a new message. This gives the agent a target and gives you a test.
Let it look first
Ask before you instruct
On anything unfamiliar, start with: read this project and tell me how it is organized. Then give the task.
One thing at a time
Break big requests into steps
Three small requests you can check are faster than one large request you have to untangle.

Write your first runbook

Module 2 explained that the agent forgets everything between sessions and that a file named CLAUDE.md is how you fix that. Make one now.

Type this to Claude
Create a CLAUDE.md file for this project. Include what the project is,
how to open it, and these rules:
- Explain what you are about to do before you change files.
- Never put passwords or API keys in code.
- Nothing is done until I have opened it and seen it work.

Close Claude Code with /exit, start it again with claude, and ask: what are the rules for this project? It will answer from the file. You have just given an agent a memory.

End every session the same way

Before you close a session where real work happened, ask for a handoff.

Type this to Claude
Write a short HANDOFF.md: what we did today, what works, what is unfinished,
and the first thing to do next time. Then commit and push.

Next time, your first message is: read HANDOFF.md and continue. Phase 4 turns this into a reusable skill.

When something goes wrong

What you see
What it means
What to do
'claude' is not recognized
The installer finished but your terminal does not know where Claude Code is.
Close Windows Terminal and open it again. If it is still not found, the official terminal guide below has a two-line fix under Windows troubleshooting.
'irm' is not recognized
You are in Command Prompt, not PowerShell.
Open Windows Terminal and check the line starts with PS. Then run the install again.
Could not create SSL/TLS secure channel
An older Windows 10 is using an outdated security setting.
The official terminal guide below has a one-line fix. Run it, then install again.
Claude Code does not support 32-bit Windows
You opened the app called Windows PowerShell (x86).
Close it. Open Windows Terminal, or the PowerShell entry without x86 in its name.
command not found: claude
The installer finished but your terminal does not know where Claude Code is.
Run the fix printed under Setup notes at the end of the install, open a new window and try again. The official terminal guide below lists the exact commands.
A page of HTML, or syntax error near unexpected token
The download returned a web page instead of the installer.
Run the install command again. If it keeps happening, use brew install --cask claude-code instead.
dyld error, or built for Mac OS X 13.0
Your macOS is older than Claude Code supports.
Update macOS to version 13 or later through Software Update.
A message that you have reached your usage limit
You have used your Pro allowance for this window.
Check your usage view for the reset time. Come back then.
Claude is changing things you did not ask for
The request was open to interpretation.
Press Esc. Tell it what to undo, then restate the task more narrowly.
The terminal is defeating you
It happens.
Open the desktop app, go to the Code tab, pick the same folder and continue there.
