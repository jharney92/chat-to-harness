Slide 5 of 12

Reading one line of a terminal

Every line starts the same way.

1

jack@macbook

Who you are: your username and computer.

2

~

Where you are. This symbol means your home folder.

3

%

The prompt. The terminal is waiting.

4

ls

Your command. Nothing happens until Enter.

Notes: Module 4. Most beginner errors are being in a different folder than you thought. Teach pwd as the reflex.
Slide 6 of 12

Six commands used constantly

CommandWhat it does
pwdShows which folder you are in.
lsLists what is in the current folder.
cdMoves into a folder. Two dots moves up one level.
mkdirMakes a new folder.
openOpens a file or folder the normal Mac way.
rmDeletes a file. There is no Trash and no undo.
Notes: Module 4 has the full fifteen. Have students run the practice exercise with a Finder window open beside the terminal.

Git: save points for a project

An agent can change twenty files in a minute. This is how you get back.

MONDAY

First version

Save.

TUESDAY

Add a form

Save.

TUESDAY NIGHT

New colors

Save.

WEDNESDAY

Agent reworks layout

It is worse. Go back one.

Notes: Module 5. Each save is a commit. GitHub keeps a copy online. Video 3 covers this in under a minute.
Slide 8 of 12

Six words students will hear daily

WordMeaning
repositoryA project folder that Git is tracking.
commitOne save point, with a note about what changed.
pushSend new commits up to GitHub.
pullBring down commits your computer does not have.
branchA parallel copy for trying something safely.
mainThe primary branch. For hosted apps, main is what is live.
Notes: Module 5. Two rules from day one: keep repositories private, and never commit a password or key.
