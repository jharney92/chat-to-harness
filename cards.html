Tool cards

Ten tools you may reach for after the guide. What each is, when it earns its place, what to ask for, and what goes wrong.

How to use these

The modules teach one path through one stack. These cards cover ten tools you may want later. Each says what the tool is, when it earns its place, what to ask the agent, and what tends to go wrong.

The setup is always the same as Phase 3: create the account, put the key in your secrets file yourself, tell the agent to read the tool's current documentation first, and say what done looks like.

Costs change. Every card says to check, and means it.

Supabase
Database and sign-in in one
What it is
A hosted Postgres database that also provides user accounts, file storage and live updates, all from one account.
Reach for it when
You are starting a new project and would like one service where this guide used Neon and Clerk separately.
Type this to Claude
Set this project up on Supabase for the database and sign-in. Read Supabase's current Next.js guide first.
Turn on row-level security so each user can only read and write their own rows, and show me the rules.
I can sign up as a second user and see nothing belonging to the first.
Watch out for
Its data protection is a feature called row-level security, and it must be switched on per table. A table without it is readable by anyone who has your public key.
Cost and where to start
Has a free tier. Check current limits. Supabase documentation
Resend
Sending email from an app
What it is
A service your app calls to send email: sign-up confirmations, receipts, a weekly digest.
Reach for it when
Your app needs to email someone. Module 12's weekly summary is a natural fit.
Type this to Claude
Add Resend so the weekly summary is emailed to each user. Read Resend's current documentation first.
Send from an Inngest step, and make that step safe to run twice.
While testing, send only to my own address.
Watch out for
This reaches real people, so it belongs behind a tier 3 gate. To send from your own address you must verify a domain. Sending the same email twice on a retry is the classic mistake.
Cost and where to start
Has a free tier with a daily cap. Check current limits. Resend documentation
Stripe
Taking payments
What it is
The standard way for an app to accept card payments and subscriptions. It has a complete test mode with fake cards.
Reach for it when
Someone would pay for what you built. Until then, test mode lets you learn the whole flow with no real money.
Type this to Claude
Add a paid plan using Stripe in TEST MODE only. Read Stripe's current documentation for hosted checkout first.
Use Stripe's hosted payment page, not a custom card form.
I can pay with a Stripe test card and see my account marked as paid.
Watch out for
Never build your own card form. Stripe tells your app about payments through messages called webhooks, and an app that does not verify them can be told it was paid when it was not. Switching to real money is a tier 3 decision.
Cost and where to start
Test mode is free. Real payments take a percentage. Stripe testing guide
File storage
Where uploads live
What it is
A service for files your users upload or your app generates: images, PDFs, audio. Vercel Blob and Cloudflare R2 are two common ones.
Reach for it when
Your app handles files. A database is the wrong place for them. Module 16's generated images are an example.
Type this to Claude
Store generated images in file storage and save only the link in the database.
Read the current documentation for the storage service first. Limit uploads to images under 5 MB.
Files belonging to one user must not be reachable by another.
Watch out for
Files are often public to anyone with the link unless you choose otherwise. Storage and downloads both cost money at volume, so cap file sizes.
Cost and where to start
Both have free allowances. Check current limits. Cloudflare R2 documentation
Playwright
A browser the agent can drive
What it is
A tool that opens a real browser and operates it by script: clicking, typing, taking screenshots.
Reach for it when
You want the agent to test your app the way a person would, or to collect information from a public web page.
Type this to Claude
Add Playwright tests for the three most important I can lines in this project.
Each test signs in as a test user and does the thing a person would do.
Run them before every merge and show me a screenshot when one fails.
Watch out for
Tests that depend on timing fail at random and teach everyone to ignore them. When scraping, read the site's terms, go slowly, and never use it to get around a login you were not given.
Cost and where to start
Free and open source. Playwright documentation
PostHog
Seeing what people do in your app
What it is
Product analytics: which pages people visit, which buttons they press, where they give up.
Reach for it when
Real people are using your app and you are guessing about what they do. You will know this territory from campaign analytics.
Type this to Claude
Add PostHog. Read its current Next.js guide first. Track sign-up, first idea created, and summary viewed.
Do not record what users type. Tell me what personal data it collects by default.
Watch out for
Analytics collect personal data. Know what you are collecting, say so in a privacy notice, and leave out anything you do not need.
Cost and where to start
Has a free tier. Check current limits. PostHog documentation
Sentry
Finding out when the app breaks
What it is
Error tracking. When your live app hits an error, Sentry records it with the details and tells you.
Reach for it when
Your app has users and you want to hear about failures from a tool before you hear from a person. It is Module 12's failure-reporting rule, for the whole app.
Type this to Claude
Add Sentry. Read its current Next.js guide first. Alert me by email on any new error in production.
Make sure no secrets or user-typed content are sent with error reports.
Watch out for
A noisy inbox gets ignored. Alert on new errors, not every repeat. Error reports can carry personal data unless you strip it.
Cost and where to start
Has a free plan for individuals. Check current limits. Sentry documentation
n8n
Automation without code
What it is
A visual tool for connecting services: when this happens there, do that here. You draw the flow as boxes and lines.
Reach for it when
The job is gluing two existing services together and there is nothing to build. Sometimes the right amount of code is none.
Type this to Claude
I want to automate this: [describe it]. Before writing any code, tell me whether a no-code automation tool would do the job,
what I would give up, and at what point it would be worth building instead.
Watch out for
Visual flows are quick to make and hard to review, test and keep history of. When one becomes important or complicated, rebuild it as code with a runbook.
Cost and where to start
Free to run yourself. The hosted version is paid. n8n documentation
Expo
Phone apps
What it is
A framework for building iPhone and Android apps using the same language and many of the same ideas as your web app.
Reach for it when
It has to be an app on a phone. First ask whether a website that works well on a phone would do. It usually does.
Type this to Claude
I am considering a phone app version of this. Read the current Expo documentation.
Tell me what would carry over from the web app, what would be new, and what publishing to the app stores involves. Do not build anything yet.
Watch out for
Publishing needs paid developer accounts and a review by Apple and Google. Everything takes longer than on the web.
Cost and where to start
Free to build with. The app stores charge. Expo documentation
Domains
Your own address
What it is
A domain is a name you rent by the year. DNS is the set of records that point that name at your app.
Reach for it when
You are showing the app to a client or putting it on a resume, and an address ending in vercel.app will not do.
Type this to Claude
I bought the domain [name]. Walk me through connecting it to this Vercel project.
Tell me exactly which DNS records to add at my registrar, one at a time, and how to check each worked.
Watch out for
DNS changes can take hours to appear. That delay is normal. Turn on auto-renew, because an expired domain takes your app and your email down with it.
Cost and where to start
Roughly the price of a couple of coffees a year for a common ending. Vercel documentation, under Domains
