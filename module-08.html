Vercel

Connect your repository once, and every push after that puts your app on the internet.

45 minutesFree

What it is

Vercel is a hosting service. It takes the code in your GitHub repository and turns it into a website anyone can visit. You connect the two once. After that, publishing is something that happens when you push.

Cost: The Hobby plan is $0. It has usage caps, and you cannot buy more on that plan: when you hit a cap you wait. The caps are far above what a learning project uses. Details on the Hobby plan page.

How your work reaches the internet

Four stops. You only act at the first one.

1
Your laptop
You and the agent change files and commit.
2
GitHub
You push. The repository now has the new commit.
3
Vercel
It notices the push, builds the app and checks that it starts.
4
The internet
The new version replaces the old one at your address.

The rule that surprises people

Once a project is connected, every push to the main branch publishes to your live site. There is no separate publish button.

From the runbook behind this guide
A push or merge to main IS the production deploy.

This is why branches matter. Work you are not sure about goes on a branch. Vercel builds each branch at its own temporary address, called a preview, and your live site is untouched until you merge.

Environment
Where it runs
Who sees it
Local
Your laptop, at localhost.
Only you.
Preview
Vercel, at a temporary address, for any branch that is not main.

Production
Vercel, at your real address, from the main branch.
Everyone.

Set it up

1
Create your account with GitHub

Go to vercel.com and choose to continue with GitHub. Signing in this way lets Vercel see your repositories.

2
Import the project

Add a new project and import campaign-notes from the list. Vercel recognizes it as a Next.js app. Leave every setting as it is and deploy.

You should see: a success screen and an address ending in vercel.app. Open it. Your three cards are on the internet.
3
Watch a push become a deployment
Type this to Claude
Change the page title to Campaign Notes: Fall Ideas. Commit and push.

Open the project's Deployments list in Vercel. A new entry appears, builds, and turns Ready. Refresh your live address.

4
Install the Vercel command-line tool
Type this
npm i -g vercel
vercel link

Linking connects this folder to the project. The agent can now check deployments and read logs for you.

5
Try a preview
Type this to Claude
Create a branch called dark-mode. Give the page a dark background with light text. Commit and push the branch. Do not merge it.

Find the new deployment in Vercel. It has its own address. Open it next to your live site and compare. The live site has not changed.

Type this to Claude
Merge dark-mode into main and push.

Now it is live.

Reading the dashboard

Where
What it tells you
Deployments
Every build, newest first, with a status. Ready means live. Error means that version never went out and the previous one is still serving.
Build logs
What happened while Vercel assembled the app. This is where you look when a deployment says Error.
Logs
What the running app prints while people use it. This is where you look when the site is up but something misbehaves.
Settings, Environment Variables
Where secrets live in production. Module 9.

When a build fails, you do not need to interpret the log. Copy the red part and give it to the agent, or ask it to read the latest deployment's logs with the Vercel tool.

When something goes wrong

What you see
What it means
What to do
Build failed, but it works on my laptop
The server is stricter than your laptop, or it is missing a setting your laptop has.
Give the build log to Claude. The usual causes are a missing environment variable or a type error.
I pushed and nothing deployed
Vercel did not accept the commit, often because the Git email does not match the account.
See Vercel's guide to commits that do not deploy.
The live site shows the old version
The newest deployment failed, so the last good one is still live.
Open Deployments and look for an Error status at the top.
A message about limits
You have used the Hobby allowance for something this period.
Wait for it to reset. It is rare on a project this size.
