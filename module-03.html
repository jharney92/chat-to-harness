Phase 2: Setup / Module 03

Your Claude account

Set up the one paid thing in this guide, and learn the three places Claude lives so you always know which one you are in.

15 minutesCosts money: one subscription

What you need

Everything in this guide runs on one paid subscription: Claude Pro. The free plan lets you chat, but it does not include Claude Code, which is the tool the rest of this guide is built on.

At the time of writing (November 2026), Pro is $20 a month billed monthly, or $17 a month if you pay for a year up front. Prices change, so confirm on the pricing page before you subscribe.

You will see larger plans called Max and Ultra. Ignore them for now. They give you more usage, and you will know if you need that because you will keep running into your limit. Most people working through this guide will not.

Three places Claude lives

One account gets you all three. Knowing which is which saves a lot of confusion later.

Chat
The Claude app
The one you already know. A conversation window on the web, your phone or your desktop. Good for questions, writing, research and thinking something through.
You do the acting. It answers.
Claude Code, terminal
The agent in a text window
You open a terminal inside a project folder and type claude. It reads the files in that folder, edits them and runs commands. This is the version this guide teaches.
It does the acting. You direct and approve.
Claude Code, desktop
The same agent with buttons
The desktop app has a Code tab that runs the same agent on a folder you pick, with no terminal involved.
A good fallback if the terminal is blocking you.

Why this guide uses the terminal

The desktop app is easier on day one. We still teach the terminal, for two reasons. The harness you build in Phase 4 lives there, with its files, scripts and scheduled jobs. And almost every tool in Phase 3 is controlled from a terminal too, so the skill pays off many times.

If you get truly stuck in Module 4, switch to the Code tab in the desktop app, keep going, and come back to the terminal later. Finishing matters more than doing it the purist way.

Set it up

1
Create your account

Go to claude.ai and sign up. Use a personal email address you will still have after you graduate. Your projects, history and subscription stay with that address.

2
Subscribe to Pro

Choose Pro on the pricing page. Pick monthly billing unless you are sure you want a full year.

3
Install the desktop app

Download it from claude.com/download and sign in. You will mostly use the terminal, but the app is useful for chat and as your fallback.

4
Find your usage

Pro has two limits: one that resets every five hours and one that resets every week. Look in your account settings for the usage view and note where it is. When an agent stops mid-task and says you have hit a limit, this is where you check when it resets.

Three questions people ask here

Question
Answer
Do I need an API key?
No. Your Pro subscription signs you in to Claude Code directly. The API is a separate, pay-as-you-go product for putting AI inside your own apps. Module 15 covers it.
Can I use ChatGPT or another tool instead?
The ideas in this guide transfer. The exact commands and file names do not. Follow along with Claude first, then apply what you learned elsewhere.
What if I hit my limit?
You wait for the reset. Use the time to read the next module. Module 20 covers habits that make your usage go further.
