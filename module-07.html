Phase 3: The stack / Module 07

Reading a project

Start the app you will build for the rest of this phase, and learn which file does what so you can follow the agent's work.

60 minutesFree

What you are learning here

From this module on, you build one app and keep adding to it: Campaign Notes, a place to save campaign ideas. By the end of Module 12 it will be live on the internet with a database, sign-in and a job that runs on a schedule.

A web app is a folder of files. The agent writes those files. Your job is to know which file does what, so you can tell where a change belongs and whether the agent put it in the right place. You are learning to read, not to write.

Two names come up constantly. Next.js is a framework: a standard way of organizing a web app, and the one most agents reach for first. Tailwind is how the app gets styled, using short codes written directly on each element.

Create the project

1
Install Node

Node runs JavaScript on your computer. Next.js needs it.

Type this
brew install nodewinget install OpenJS.NodeJS.LTS
node --version
You should see: a version number of 20 or higher.
2
Create the app
Type this
cd ~/Code
npx create-next-app@latest campaign-notes --yes

The --yes flag accepts the standard setup, which includes Tailwind and a file called AGENTS.md that tells coding agents how to work with this version of Next.js.

3
Run it on your own computer
Type this
cd campaign-notes
npm run dev
You should see: a line with the address http://localhost:3000. Open it in your browser.

Localhost means your own computer is serving the site. Nobody else can see it. Leave this running, and press Ctrl + C in this tab when you want to stop it.

4
Start Claude in a second tab

Press Cmd + T for a new tab.Press Ctrl + Shift + T for a new tab.

Type this
cd ~/Code/campaign-notes
claude
Type this to Claude
Read this project and explain the folder structure to someone who has never written code.

How to read a page

Open app/page.tsx. Stripped down, a page looks like this.

In the file
export default function Home() {
return (
<main className="p-8">
<h1 className="text-2xl font-bold">Campaign Notes</h1>
<p className="text-gray-600">Ideas worth keeping.</p>
</main>
);
}
Part
What it means
function Home()
A component: one named piece of a page. Pages are built from components the way a layout is built from blocks.
The part that looks like HTML
What appears on screen. An h1 is a headline, a p is a paragraph.
className
The styling for that element, written as Tailwind codes.

A Tailwind decoder

You do not need to memorize Tailwind. You need to recognize it. Most codes are an abbreviation plus a size.

Code
Meaning
p-8 m-4
Padding inside, margin outside. Bigger number, more space.
text-2xl font-bold
Text size and weight.
text-gray-600 bg-white
Text color and background color.
flex gap-4
Lay children out in a row or column, with space between them.
rounded-lg border
Rounded corners and an outline.
md: prefix
Only applies on medium screens and larger. This is how one page fits both phone and laptop.

Front end and back end

Some of your app's code runs in the visitor's browser. That is the front end. Some runs on a server the visitor never sees. That is the back end.

The difference matters for one reason above all: anyone can read front-end code. Passwords, keys and database access belong on the back end only. Module 9 comes back to this.

When something goes wrong

What you see
What it means
What to do
npm is not recognized, or running scripts is disabled
The terminal was open before you installed Node, or the script setting from Module 4 was skipped.
Close Windows Terminal and open it again. If it says scripts are disabled, run the Set-ExecutionPolicy line from Module 4.
npm: command not found
Node is not installed, or the terminal was open before you installed it.
Run brew install nodewinget install OpenJS.NodeJS.LTS, then open a new terminal tab.
Port 3000 is in use
Another copy of the app is already running.
Read the terminal. It will have picked another port, such as 3001. Or find the old tab and press Ctrl + C.
Module not found
A piece of outside code is missing.
Run npm install, then start the app again.
A red error screen in the browser
The code has a mistake the app cannot recover from.
Copy the whole message and paste it to Claude.
The page looks unstyled
Tailwind is not being applied.
Ask Claude to check the Tailwind setup against the current Next.js docs.
